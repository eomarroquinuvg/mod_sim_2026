📐 Euler paso a paso

Observa cómo el método de Euler utiliza la pendiente actual del sistema para estimar cuál será su siguiente estado.

MÉTODO DE EULER yₙ₊₁ = yₙ + h · f(tₙ,yₙ)

Cálculo de Euler

Seguimos exactamente los pasos de la fórmula.

PASO 0
tₙ 0
Tₙ 90.00 °C
h 1 min
1. Calcular la pendiente
f(t₀,T₀) = -0.1(90 - 20)
= -7.00 °C/min
💡
¿Qué significa?

La pendiente es negativa porque la temperatura está disminuyendo.

2. Aplicar Euler
Tₙ₊₁ = Tₙ + h · f(tₙ,Tₙ)
T₁ = 90 + 1(-7)
T₁ = 83.00 °C
👣
Nuevo estado

IDEA CENTRAL

Euler mira la pendiente actual

Euler supone que durante el siguiente intervalo la pendiente actual es una buena aproximación del comportamiento del sistema. Por eso avanza utilizando una línea recta durante cada paso.

Estado actual → Pendiente → Avanzar h → Nuevo estado
