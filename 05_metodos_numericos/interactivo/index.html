03 · CONEXIÓN CON EL CURSO

¿Por qué esto es simulación?

Un sistema real cambia continuamente. Una computadora necesita representar esa evolución mediante cálculos discretos. Los métodos numéricos permiten avanzar paso a paso y construir una aproximación del comportamiento del sistema.

Sistema real → Modelo matemático → Método numérico → Simulación → Análisis
