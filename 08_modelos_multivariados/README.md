# 08 - Modelos Multivariados

## CC3074 - Modelización y Simulación
Universidad del Valle de Guatemala — 2026

Este módulo trabaja los modelos multivariados siguiendo la secuencia:

**Concepto → ejemplo manual → programación → simulación → interpretación**

## Contenidos
- Vectores de variables aleatorias
- Vector de medias
- Varianza
- Covarianza
- Correlación
- Matriz de covarianza
- Matriz de correlación
- Distribución normal multivariada
- Variables correlacionadas
- Descomposición de Cholesky
- Caso aplicado: demanda y tiempo de entrega

## Instalación

```bash
pip install -r requirements.txt
```

## Idea principal

Un modelo multivariado no consiste únicamente en simular varias variables. Debe representar también la **relación existente entre ellas**.

La carpeta `interactivo/` queda reservada para la siguiente etapa y no modifica ninguno de los módulos anteriores.
