🚗 Flujo Máximo y Costo Mínimo

Una red puede representar carreteras, tuberías, enlaces de comunicación o rutas de transporte. Cada conexión tiene límites que debemos respetar.

flujo ≤ capacidad
s
Fuente

Nodo donde se origina el flujo.

t
Destino

Nodo donde queremos hacer llegar el flujo.

c
Capacidad

Máximo flujo permitido en una conexión.

f
Flujo

Cantidad que actualmente utiliza la conexión.
