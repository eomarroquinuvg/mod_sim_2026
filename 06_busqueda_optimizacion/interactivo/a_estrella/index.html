BÚSQUEDA INFORMADA

⭐ A* (A-estrella)

A* busca un camino hacia una meta combinando el costo que ya hemos recorrido con una estimación de cuánto falta para llegar.

f(n) = g(n) + h(n)
g(n)
Costo acumulado

Cuánto hemos gastado para llegar desde el inicio hasta el nodo n.

h(n)
Heurística

Estimación de cuánto falta desde n hasta la meta.

f(n)
Evaluación

Valor que A* utiliza para decidir qué nodo explorar.

📏 Heurística utilizada

Utilizamos distancia Manhattan:

h(n) = |fila actual - fila meta| + |columna actual - columna meta|

Esta estimación funciona bien porque el robot solo puede moverse horizontal o verticalmente.

Recuerda

A* no observa únicamente cuánto ha recorrido. También utiliza una estimación de cuánto falta.

g(n) + h(n) = f(n)
